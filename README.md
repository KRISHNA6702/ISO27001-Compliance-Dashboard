# ISO 27001 Compliance Dashboard

A web-based cybersecurity compliance dashboard designed to simplify information security management, risk assessment, and ISO 27001 compliance monitoring.

## About the Project

The ISO 27001 Compliance Dashboard is a college-level cybersecurity project focused on Information Security Management Systems (ISMS).

It aims to provide organizations with a centralized interface to monitor security compliance, assess potential risks, and track information security controls based on the ISO/IEC 27001 framework.

## Objectives

- Simplify information security compliance monitoring.
- Provide visibility into security risks.
- Track implementation of security controls.
- Organize compliance-related information.
- Present security metrics through a centralized dashboard.

## Key Features

- **Compliance Dashboard:** Overview of compliance status and security metrics.
- **Risk Assessment:** Identification and evaluation of potential security risks.
- **Security Controls:** Monitoring of information security controls.
- **Compliance Monitoring:** Track progress toward security requirements.
- **Visual Reporting:** Present compliance-related information in an organized interface.

## Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR_USERNAME/ISO27001-Compliance-Dashboard.git
```

### 2. Navigate to the Project Directory

```bash
cd ISO27001-Compliance-Dashboard
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

### 5. Open in Browser

Visit the local URL provided by Vite, usually:

```text
http://localhost:5173
```
